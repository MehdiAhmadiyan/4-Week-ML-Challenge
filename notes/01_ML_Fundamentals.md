# 🧠 Fundamentals of Machine Learning

## 1. Supervised Learning
**Concept:** The algorithm learns from being given the "right answers" (labeled data). It essentially learns to map input features ($X$) to an output label ($Y$).

*   **Regression:** Predicts a continuous number from infinitely many possible outputs (e.g., predicting house prices).
*   **Classification:** Predicts discrete categories (small number of possible outputs). 
    *   Can have multiple input features.
    *   Visually, it creates a **boundary line** (decision boundary) between different categories.

## 2. Unsupervised Learning
**Concept:** The algorithm is given unlabeled data and must find interesting patterns, structures, or groupings on its own (no supervision).

*   **Clustering:** Groups unlabeled data into distinct clusters based on similarity.
    *   *Examples:* Google News (grouping related articles), Customer Segmentation, DNA microarray analysis.
*   **Anomaly Detection:** Identifies unusual data points or rare events (e.g., fraud detection).
*   **Dimensionality Reduction:** Compresses a large dataset into fewer numbers/features without losing the core information.

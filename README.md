# 🚀 4-Week Machine Learning Challenge

Welcome to my 4-Week Machine Learning Challenge repository! 

## 🧠 About This Challenge
I am not an absolute beginner in Machine Learning. I have previously explored the field and studied the official **Scikit-Learn documentation**. However, my knowledge was a bit scattered. 

The primary goal of this repository is to **structure, organize, and solidify** my existing knowledge while building a strong, practical foundation through daily coding and consistent commits. This challenge is about taking disconnected pieces of information and turning them into a cohesive, well-organized skill set.

## 🎯 Objectives
*   **Review and Structure:** Bring order to the ML concepts I've previously learned.
*   **Hands-on Practice:** Transition from reading documentation to writing functional code and building end-to-end pipelines.
*   **Consistency:** Maintain a steady streak of learning, coding, and committing.
*   **Deepen Understanding:** Re-visit core algorithms with a focus on implementation, mathematical intuition, and real-world application.

## 📂 Repository Structure
*   `📁 notes/` - My personal summaries, formulas, and theoretical takeaways.
*   `📁 notebooks/` - Jupyter Notebooks containing the implementation of different algorithms and models.
*   `📁 scripts/` - Python scripts for data preprocessing or model training.

---

## 🗺️ Core Topics Covered

Throughout this challenge, I will be implementing and organizing concepts covering the fundamental spectrum of Machine Learning:

*   **End-to-End ML Pipeline:** Data exploration, cleaning, feature engineering, and scaling.
*   **Regression Models:** Linear Regression (Univariate & Multivariate), Cost Functions, and Gradient Descent.
*   **Classification Models:** Logistic Regression, Softmax, and evaluating performance (Precision, Recall, F1-Score, ROC/AUC).
*   **Model Tuning & Generalization:** Regularization (L1/L2), handling Overfitting/Underfitting, and Hyperparameter tuning.
*   **Support Vector Machines (SVM):** Linear and Non-linear classification, Kernel trick.
*   **Tree-Based Models:** Decision Trees, Random Forests, and Ensemble Learning concepts.
*   **Unsupervised Learning:** K-Means Clustering, Principal Component Analysis (PCA) for dimensionality reduction, and Anomaly Detection.
